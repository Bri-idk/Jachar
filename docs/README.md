# Building JaChar

#### This project born from the necessity of learning Java for software development for my profesional career. So basically is not something you need use, but I needed build.

## So, why a notepad?
And the answer is... why not? XD.

I’m joking, actually building a notepad helps you a lot to the understatement of how the programs handle exceptions and files.

This is not the most complex or entertaining program to do, but it gives you a lot just because it asks for full underinvestment of the basical topics.
Conditionals, loops, exceptions and more.

## Challenges and Takeaways
* **Getting out from the basic terminal program:** Building a UI for me is actually some of the most hard things to do, mostly for the fact that I didn't make one before (web development is different for me xd). So this AWT thing is most of the challenge


* **Exception handling:** This is one thing that you don't think about it most part of the time but when you see that your program explotes, and you don't know why, you remember why it is important 

* **Modularization of the code:** Having a fully functional monolith is cool but having a fully readable code is the best thing if you don't want to get lost in you code.


* **Write readmes:** Sounds fun but is actually some of the more boring things to do on a project, and it is more tedious because I have low expectations about the people that actually is going to read all this stuff.  

## What I would do differently today?
I would better define the goals and what I truly want to achieve with the project. This because I lost time finding out what I was going to make.
